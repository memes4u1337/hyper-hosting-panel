HYPER-HOST v95 — CP WOW UI + AUTO BOT DEPLOY

Установка поверх существующей панели:
  unzip hyper-hosting-panel-v95-cp-wow-patch.zip
  cd hyper-hosting-panel-v95-cp-wow-patch
  sudo bash update.sh

Что изменено:
- полностью обновлён внешний вид клиентской CP;
- Font Awesome и новый premium dark/glass интерфейс;
- адаптивное меню и улучшенные карточки/формы/статусы;
- создание бота через загрузку основного файла + .env + requirements.txt/package.json;
- автоматическое создание окружения, установка зависимостей, systemd автозапуск и запуск бота;
- Python и Node.js;
- безопасная передача upload-файлов через root bridge с проверкой пути и размера;
- выдача ресурсов клиенту через проценты RAM/диска с живым расчётом объёма;
- CPU выдаётся ползунком, ниже показывается эквивалент в ядрах;
- в таблице клиентов показываются и проценты, и фактически выданный объём;
- удалены лишние формулировки «ваш/наш» из клиентской части;
- update.sh теперь работает как sparse-патч, делает backup и rollback при ошибке.

Резервные копии update.sh сохраняет в:
  /opt/hyper-host/backups/v95-cp-<дата-время>
