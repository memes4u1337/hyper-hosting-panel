HYPER-HOST v96 — PREMIUM CP / AUTO DEPLOY

Установка поверх существующей панели:
  unzip hyper-hosting-panel-v96-premium-cp-patch.zip
  cd hyper-hosting-panel-v96-premium-cp-patch
  sudo bash update.sh

Что изменено в v96:
- клиентская CP полностью перерисована в premium hosting-style интерфейсе;
- светлая широкая рабочая область + тёмный профессиональный sidebar;
- новый dashboard без огромных пустых зон: hero, ресурсы, состояние инфраструктуры, события и быстрые разделы;
- новые карточки сайтов, ботов, SSL, FTP, логов, формы, кнопки, статусы и адаптив;
- исправлено отображение нулевого использования RAM/диска: теперь 0.0 MB вместо неинформативного B;
- Font Awesome используется для интерфейсных иконок;
- сохранён автодеплой ботов: загрузка bot.py/index.js + .env + requirements.txt/package.json;
- зависимости ставятся автоматически, создаётся systemd unit, включается автозапуск и бот запускается;
- Python и Node.js;
- выдача ресурсов клиентам в основной панели остаётся через проценты с автоматическим расчётом фактического объёма;
- update.sh делает backup и rollback при ошибке.

Резервные копии update.sh сохраняет в:
  /opt/hyper-host/backups/v96-cp-<дата-время>
