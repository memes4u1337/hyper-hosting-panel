# HYPER CLOUD v107 — Editor / Preview / Security / UI

## Что исправлено

- Редактор вынесен в отдельный `/editor.php` и больше не зависит от большого монолитного маршрута Cloud.
- HTML preview вынесен в `/site.php`, ресурсы сайта обслуживает подписанный `/site-resource.php`.
- Installer выполняет реальный авторизованный smoke-test: открыть редактор, сохранить HTML, открыть preview и получить HTML через signed-resource. При HTTP 500 установка останавливается и показывает хвост Cloud PHP error log.
- Все старые ссылки вида `?edit=1` и старый HTML-preview перенаправляются на новые endpoints.
- Редактор поддерживает обычные файлы и редактируемые записи ZIP/7Z/RAR (RAR — если установлен `rar`).

## Интерфейс

- Переработано левое меню и визуальная иерархия.
- Новые цветные Font Awesome иконки типов файлов и разделов.
- На карточках кода отображается тип файла (HTML/PHP/CSS/JS и т.д.).
- `.html/.htm`: отдельное действие «Открыть сайт» и отдельное действие редактирования кода.
- Убраны подсказки на форме входа о данных администратора/пароле панели.

## Усиление безопасности

- Cloud работает в отдельном системном пользователе `hypercloud` и отдельном PHP-FPM pool `/run/php/hypercloud.sock`.
- PHP-код приложения root-owned и недоступен на запись Cloud-процессу.
- Cloud-процессу через POSIX ACL запрещено читать SQLite/config панели.
- Проверка аккаунтов панели делается через узкий root helper `/usr/local/sbin/hyper-cloud-panel-auth`; наружу не выдаются хеши паролей или содержимое базы панели.
- Rate limit входа и регистрации.
- Secure + HttpOnly + SameSite session cookie, strict sessions, idle/absolute expiration.
- CSRF на изменяющих запросах.
- Защита от path traversal и symlink escape.
- HTML preview загружается в sandboxed iframe без `allow-same-origin`; ресурсы preview выдаются только по короткоживущей HMAC-подписанной ссылке.
- Код PHP/ENV/SQL не выдаётся через ресурсный endpoint HTML-preview.
- Public-share preview не выполняет произвольный HTML/код inline.
- Nginx использует отдельный Cloud FPM socket и security headers.

## Важно

Абсолютной гарантии от компрометации не существует. v107 заметно уменьшает blast radius: Cloud больше не имеет постоянного прямого доступа к базе панели и не может менять свой PHP-код. При этом все Cloud-файлы обслуживаются одним системным пользователем `hypercloud`; критичные секреты не стоит использовать как единственное резервное/секретное хранилище без дополнительного шифрования.
