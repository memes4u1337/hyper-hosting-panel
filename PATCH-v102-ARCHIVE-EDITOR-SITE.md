# HYPER CLOUD v102 — архивный редактор + запуск HTML как сайта

## Исправлено

- Исправлено чтение текстовых файлов внутри ZIP/7Z/RAR, в том числе архивов, где пути сохранены как `./folder/file.ext`.
- Пустые текстовые файлы внутри ZIP теперь открываются корректно, а не как ошибка чтения.
- Убрана проблемная передача `--` в команды 7-Zip; улучшен разбор списка 7z/7zz.
- При сохранении файла архив ищет реальное внутреннее имя и не теряет вложенный путь.
- ZIP продолжает редактироваться через `ZipArchive`, а при его отсутствии — через `unzip/zip`; 7Z — через 7z/7zz; RAR — если установлен `rar`.
- Перед изменением архива, как и раньше, создаётся резервная копия.

## HTML / HTM

- Клик по `.html/.htm` теперь открывает сайт **отдельно в новой вкладке**, а не прячет его внутри обычного просмотрщика.
- Рядом с HTML есть отдельное действие **Редактировать код**.
- В редакторе HTML есть кнопка **Открыть сайт**.
- Корневые ссылки вида `/css/style.css` корректно разрешаются относительно корня сайта, а не корня всего Cloud.
- Сохраняется работа относительных CSS/JS/изображений, CSS `url(...)`, `@import` и базовых ES-module `import`.
- HTML внутри ZIP/7Z/RAR тоже можно открыть отдельной страницей как сайт; его соседние CSS/JS/изображения выдаются прямо из архива через защищённый backend.

## Редактор

- PHP, HTML, CSS, JS, JSON, SQL, Python, TXT, ENV, YAML и другие текстовые файлы снова открываются в редакторе.
- Для обычных файлов кнопка редактирования доступна прямо на карточке и в режиме списка.
- Для файлов внутри архива отдельно показаны действия `Открыть как сайт` (HTML) и `Редактировать код`.
- Лимит редактора: 2 МБ на один текстовый файл.

## Безопасность

- Cloud по-прежнему требует авторизацию HYPER-HOST.
- HTML preview не публикует файл наружу и работает только в авторизованной сессии.
- Пути внутри архивов нормализуются и не могут выйти через `../`.
- Публичные ссылки и пользовательские файлы этим патчем не сбрасываются.
